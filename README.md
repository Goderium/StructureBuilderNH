# StructureBuilderNH

面向 GTNH 的多方块建造工具。无线结构蓝图可以读取 GT 主机的 StructureLib 结构，预览占地、轮廓和仓室位置，并分批搭建。

## 无线结构蓝图

1. 用 StructureLib 蓝图和 AE2 无线终端无序合成无线结构蓝图。要使用 ME 库存和自动合成，先在 ME 安全终端配对。
2. 右键已有主机，或右键方块表面选择新主机的位置。空中右键会选择玩家脚部所在的方块。新建时可从 NEI 拖入主机标记。
3. 在蓝图中调整结构信道和每秒放置格数，查看耗材，按「开始」搭建。生存模式可使用背包和 ME 库存中的材料，包括可凿成目标方块的变体。创造模式直接放置。
4. 缺料时可从 ME 下单。备齐后默认等待手动开工，也可在下单时勾选「备齐后自动搭建」。潜行空中右键打开任务列表，可查看各处的建造进度。

从 0.2.0 起，模组 ID 为 `structurebuildernh`。旧版蓝图和任务不会迁移。

## 创造模式重建

默认保持原生蓝图行为。创造模式下，将蓝图的 `rebuild` 信道设为 `1`，手持蓝图潜行右键控制器，即可先清空本次所有结构片段的长方体包围盒（包含片段间空隙），再执行原生蓝图放置。无需为每台机器单独接入，移除该信道即可关闭重建。

预清空会跳过容器、配置白名单中的方块，以及其他已成型 GT 机器的结构范围；普通结构方块不会仅因带有方块实体而被保留。白名单可按模组或方块编辑，默认包含 AE、常见 AE 附属模组及储物模组。保护仅作用于预清空，后续原生放置仍可按新结构替换方块；生存模式与结构预览保持原有行为。

每次重建的调试记录保存在 `logs/structurebuildernh/`，可在配置中调整日志详细程度。
